# Podcast de IA com Voz Sintética

## 📒 Descrição
Este projeto explora o uso de IA para criar um podcast sobre o impacto das IAs Generativas no desenvolvimento de conteúdo. Utilizando uma voz sintética, discutimos como essas tecnologias estão moldando o futuro.

## 🤖 Tecnologias Utilizadas
- **ChatGPT** para gerar o roteiro do podcast.
- **Descript** ou **Murf.AI** para gerar a voz sintética.
- **Audacity** para edição de áudio.

## 🧐 Processo de Criação
1. O roteiro foi criado usando o ChatGPT, focando no tema de como as IAs estão transformando o mercado de trabalho.
2. Utilizamos uma IA de voz sintética (como Murf.AI) para narrar o texto.
3. O áudio foi editado e finalizado no Audacity, para garantir a qualidade e fluidez.

## 🚀 Resultados
O podcast foi gerado com sucesso e está disponível para audição. Confira o áudio final abaixo.

## 💭 Reflexão
Criar conteúdo "natty" com IA é desafiador, pois é necessário garantir que a voz sintética soe natural, além de fazer com que o conteúdo seja informativo e envolvente. A IA pode ser uma ferramenta poderosa, mas é importante não perder a humanidade no processo.
